# Contributing

Thanks for helping improve METOO Bluetooth Monitor!

## Before opening an issue

Please include:
- Windows version
- Mouse model and firmware/software revision
- Whether the mouse is paired in Windows
- Whether you are running the EXE or Python source
- Relevant log excerpts (remove personal information)

## Pull requests

1. Keep changes focused.
2. Test on Windows 10/11 where possible.
3. Do not add battery percentage estimates unless the device exposes a real battery-level characteristic.
4. Update the README when behavior or setup changes.
5. Keep the application lightweight and local-first.
